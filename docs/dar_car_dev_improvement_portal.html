15 Zero Exit Gate — قانون انتقال المراحل

غير قابل للتجاوز. لا تُفتح المرحلة التالية (ولا يُعلن Conditional / Commercial GO) إلا بعد تحليل خروج المرحلة الحالية ونجاح هذه البوابة. أي انتقال بدون تقرير خروج موقّع = انتهاك للدستور.

القاعدة الرسمية

بعد إكمال مرحلة N: 1) تشغيل تحليل الخروج (حرج / تحذير / معلومات) على نطاق المرحلة 2) Critical (P0 / Errors / Blockers في النطاق) = 0 ← مطلق 3) Warnings (P1 / تحذيرات النطاق) = 0 ← أو Waiver موقّع 4) Info = يُبلَّغ · لا يحجب 5) Deferred المعتمد في الدستور = ليس عيباً مفتوحاً 6) فقط عند PASS → فتح مرحلة N+1

مستويات النتيجة

المستوىيشمليحجب الانتقال؟الفعل المطلوب
Critical P0 · Analyzer errors · Merge blockers · عيوب أمن/سلامة داخل نطاق المرحلة · انحدار جديد بعد الدمج نعم — صفر مطلق أصلح ثم أعد التحليل. لا تنازل إلا بلجنة + توثيق استثنائي نادر جداً.
Warning P1 · Analyzer warnings داخل blast radius للمرحلة · ثغرات قبول غير مغلقة نعم — صفر أو Waiver أصلح، أو سجّل Waiver موقّع (مالك + مراجع + سبب + تاريخ مراجعة).
